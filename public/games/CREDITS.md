# Game credits

Games marked **self-hosted** are copied into `public/games/` so they load
reliably from any host. They keep their own licenses (included in each folder).
Everything else is loaded from the author's own GitHub Pages site.

- `public/games/hextris/` is GPL-3.0 and was trimmed (external analytics and
  the expired-certificate script were removed; the Google font link was
  dropped so it works offline). Its `LICENSE.md` is included.
- Third-party games are embedded from their public demos. If an author asks
  for a game to be removed, delete its entry in `assets/games.js`.
